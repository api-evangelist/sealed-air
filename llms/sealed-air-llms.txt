# Sealed Air

> Sealed Air Corporation (SEE) is a global packaging company headquartered in Charlotte, North Carolina, now privately held following its acquisition by Clayton, Dubilier & Rice. It designs and manufactures food packaging, protective packaging and automated packaging equipment under the Bubble Wrap, Cryovac, AutoBag, Liquibox and NexCel brands, and pairs them with digital services including SEE Smart Service Link for connected-equipment monitoring and prismiq for digital printing and smart packaging.

## API surface

Sealed Air runs an API program on Microsoft Azure API Management, but no part of the contract is
public. There is no OpenAPI, AsyncAPI, GraphQL SDL, MCP server, agent card, llms.txt, security.txt or
client SDK published on any Sealed Air host as of 2026-08-28.

- Production developer portal: https://developer.sealedair.com/ — live, but Azure API Management
  content has never been published; every path returns the default "content hasn't been published
  yet" placeholder.
- Published developer portal (system-integration-test host): https://sit-developer.sealedair.com/ —
  "We provide industry-leading APIs for Sealed Air", with Sign up / Sign In and an APIs page. The
  portal's data API refuses anonymous listing (HTTP 401), so the API catalog cannot be read without
  an account.
- SEE Smart Service Link cloud gateway (demo): https://see-link-cloud-gateway-demo.digital.sealedair.com/V1/API
  — referenced from the demo UI's own JavaScript bundle; returns HTTP 401 on every path.

An agent cannot call any Sealed Air API without first obtaining a developer-portal account.
